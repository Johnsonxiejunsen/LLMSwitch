# ccx A期 实施计划 v1

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 实现 spec v1.0 的 A期：`ccx` 启动器（号池自动选号 + preflight 预检 + `--settings` 临时文件注入）+ ccx 插件（/modelx、SessionStart hook）。

**Architecture:** 全部逻辑在 `bin/ccx-core.psm1`（可单测的纯函数层），`bin/ccx.ps1` 是薄 CLI 入口；插件部分（command/hook）复用同一 ccx.ps1。无常驻件。registry/state 在 `~/.claude/model-accounts/`（事实源，永不入仓）；settings.json 是仅由 `set-default` 显式同步的派生快照。

**Tech Stack:** PowerShell 5.1（零外部依赖，含 Pester 都不装——自带 test harness）；插件清单 JSON。

**Spec:** `D:\program\claude-tools\ccx\docs\features\ccx\specs\ccx.md`（v1.0，含 P1–P7 实证与全部拍板）——本 plan 从 spec 取值，执行者两份都读。

## Global Constraints

- **PS 5.1 禁用**：`&&`、`||`、三元、`??`、`?.`；`Out-File -Encoding utf8` 带 BOM——**一切 JSON 文件必须用** `[System.IO.File]::WriteAllText($p, $json, [System.Text.UTF8Encoding]::new($false))`（无 BOM，claude 是 node，BOM 会炸 JSON.parse）。**反向规则（Task 1 实抓）：一切含中文的 `.ps1` 必须带 BOM**——PS 5.1 对无 BOM 文件按 ANSI/GBK 解析，中文必炸且可能假绿
- **红线**：token/真实凭据零入仓；`~/.claude/model-accounts/` 不进仓。**Git 政策（用户已授权"做好后上传"）**：在 `feat/ccx-a` 分支**每任务本地 commit**（不出仓）；**push 仅终末一次**（Task 12 人工门签字 + 卫生门终跑后，推 gitee origin + 内部 GitLab，后者 remote 届时添加）
- **不破坏**：裸 `claude` 行为分毫不动；settings.json 唯一写入口 = `set-default`（写前必备份）
- **路径缝（测试用，默认值即真实路径）**：`CCX_HOME`（默认 `$env:USERPROFILE\.claude\model-accounts`）、`CCX_SETTINGS_PATH`（默认 `~\.claude\settings.json`）、`CCX_PROFILE_PATH`（默认 `$PROFILE`）、`CCX_CLAUDE_CMD`（默认 `claude`）
- 中文面板输出：ccx.ps1 入口处 `try { [Console]::OutputEncoding = [Text.Encoding]::UTF8 } catch {}`（GBK 管道坑）
- 时间一律本地时区，ISO8601 字符串存 state
- r429 冷却默认 60s；daily 恢复 = 该号 `reset_time`（默认 "00:00"）的下一次到来；blocked 仅 `unlock`

## Review Focus（spec 未点名、最可能咬人的输入类 → 已钉进对应任务）

### Task 5: preflight 预检 + 失败分类 + 接力

**Files:**
- Modify: `bin/ccx-core.psm1`
- Test: `test/test_preflight.ps1`

**Interfaces:**
- Consumes: Task 3 Set-CcxAccountStatus、Task 4 Select-CcxAccount
- Produces:
  - `Invoke-CcxProbe -Account <hashtable> [-Probe <scriptblock>] → @{Status=<int>;Body=<string>;NetworkError=<bool>}`：默认实现 POST `<base_url>/v1/messages`，headers `Authorization: Bearer <token>`、`anthropic-version: 2023-06-01`，body `{"model":<env.ANTHROPIC_MODEL>,"max_tokens":1,"messages":[{"role":"user","content":"hi"}]}`，超时 10s；入口先设 `[Net.ServicePointManager]::SecurityProtocol='Tls12'`；`-Probe` 是测试注入口
  - `Invoke-CcxPreflight -Account [-Probe] → @{Ok;Marked=<'blocked'|'r429'|'daily'|$null>;Detail}`：分类顺序 **401→blocked → Body 匹配 `(?i)余额|欠费|insufficient|额度|exhaust` → daily → 429→r429 → 其余(含 NetworkError/超时/5xx)→不标只警告**
  - `Select-AndPreflight -Registry -State -Group [-NoCheck] [-StrongId <string>] [-Probe] → @{Account;Warnings=<string[]>;Panel=<string>}`：循环选号→预检，失败已标记者换下一号，上限=池大小；`StrongId` 时预检失败**不接力**（警告后仍返回该号，尊重强指）；`-NoCheck` 跳过预检；全不可用时 Account=$null 且 Panel=全池面板
  - `Invoke-CcxCheck -Registry -State`（= 全池逐号预检 + 面板，`ccx check` 用）

- [ ] **Step 1: 失败测试**（全部走 -Probe 注入，零真实网络）：①401→Marked=blocked 且 state 已写 ②Body 含「余额不足」→daily ③429→r429 ④超时(NetworkError=$true)→Marked=$null、Ok=$false ⑤接力：glm-2 预检 401、glm-3 ok → 返回 glm-3 且 glm-2 已标 blocked ⑥StrongId+死号 → 仍返回该号+Warnings 非空 ⑦全死 → Account=$null+Panel
- [ ] **Step 2: 失败 → 实现 → PASS**
